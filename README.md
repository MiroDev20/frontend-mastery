# frontend-mastery

**Domina el desarrollo frontend desde cero hasta proyectos profesionales.**

---

## 📘 ¿Qué es frontend-mastery?

`frontend-mastery` es un proyecto educativo integral diseñado para guiarte a través de todos los aspectos del desarrollo frontend moderno. Desde los fundamentos de HTML, CSS y JavaScript, hasta técnicas avanzadas como animaciones, accesibilidad, consumo de APIs, manejo del DOM, y creación de componentes reutilizables. Cada módulo está pensado para ser práctico, progresivo y centrado en ejemplos del mundo real.

El proyecto está estructurado en carpetas temáticas, cada una con su propio `README.md` que explica la teoría, muestra ejemplos de código y propone ejercicios para afianzar los conocimientos. Al final, dispondrás de una carpeta `projects/` donde podrás poner en práctica todo lo aprendido construyendo aplicaciones completas.

---

## 🎯 Objetivos generales

Al completar este proyecto, serás capaz de:

- Maquetar interfaces web semánticas y accesibles con HTML5.
- Estilizar páginas con CSS moderno (Flexbox, Grid, animaciones, responsive).
- Programar interactividad y lógica con JavaScript (ES6+, asincronía, DOM).
- Consumir APIs REST y manejar datos asíncronos.
- Crear componentes reutilizables y gestionar el estado de la aplicación.
- Aplicar principios de accesibilidad (WCAG) y buenas prácticas de usabilidad.
- Utilizar formatos vectoriales (SVG) y multimedia (audio, canvas).
- Construir proyectos completos desde el diseño hasta la implementación.

---

## 📂 Estructura del proyecto

Cada carpeta contiene un `README.md` con la teoría, ejemplos y roadmap del tema. La estructura está organizada para seguir una curva de aprendizaje lógica:

| Carpeta | Descripción |
|---------|-------------|
| [`html/`](./html) | Fundamentos de HTML5: etiquetas semánticas, formularios, tablas, SEO básico. |
| [`css/`](./css) | CSS desde cero: selectores, modelo de caja, Flexbox, Grid, responsive, preprocesadores. |
| [`javascript/`](./javascript) | JavaScript esencial: sintaxis, tipos, funciones, arrays, objetos, asincronía, ES6+. |
| [`dom/`](./dom) | Manipulación del DOM: selección, eventos, creación/eliminación de elementos, rendimiento. |
| [`forms/`](./forms) | Manejo avanzado de formularios: validación, envío, estilado, accesibilidad. |
| [`responsive/`](./responsive) | Diseño responsive: media queries, unidades relativas, enfoque mobile-first. |
| [`animations/`](./animations) | Animaciones en CSS y JavaScript: transitions, keyframes, animaciones con JS. |
| [`accessibility/`](./accessibility) | Accesibilidad web (a11y): ARIA, navegación por teclado, contraste, lectores de pantalla. |
| [`canvas/`](./canvas) | Dibujo y gráficos 2D con Canvas API: formas, imágenes, animaciones. |
| [`svg/`](./svg) | Gráficos vectoriales con SVG: creación, estilado, animación, integración. |
| [`audio/`](./audio) | Reproducción y manipulación de audio con Web Audio API. |
| [`apis/`](./apis) | Consumo de APIs REST: fetch, async/await, manejo de errores, autenticación. |
| [`components/`](./components) | Creación de componentes reutilizables con JavaScript vanilla o frameworks (si se incluyen). |
| [`projects/`](./projects) | Proyectos prácticos que integran todos los conceptos: landing page, app de tareas, etc. |

## 🧭 Cómo usar este proyecto

1. **Clona el repositorio** (o descarga los archivos):
   ```bash
   git clone https://github.com/tuusuario/frontend-mastery.git
   cd frontend-mastery
   ```

2. **Explora los módulos en orden** (recomendado) o salta a los que más te interesen:
   - Empieza por `html/`, luego `css/` y después `javascript/` para construir una base sólida.
   - Continúa con `dom/`, `responsive/`, `animations/` y `apis/` para ampliar tus habilidades.
   - Finaliza con `projects/` para aplicar todo lo aprendido en proyectos completos.

3. **Ejecuta los ejemplos de código**:
   - Cada módulo incluye fragmentos de código HTML, CSS y JavaScript.
   - Puedes crear archivos `.html` y abrirlos en tu navegador, o usar herramientas como Live Server en VS Code.
   - Experimenta modificando los ejemplos para profundizar en los conceptos.

4. **Consulta la documentación oficial** cuando necesites más detalles – los enlaces están al final de cada README.

5. **Practica y construye proyectos pequeños** combinando varios módulos.

## 📖 Recomendaciones de estudio

- **Lee cada README** de principio a fin, prestando atención a los roadmap y ejemplos.
- **Escribe tu propio código** a medida que avanzas; no te limites a copiar y pegar.
- **Prueba las herramientas** de desarrollo del navegador (DevTools) para depurar y experimentar.
- **No temas equivocarte** – los errores son parte del aprendizaje.
- **Comparte dudas** en foros o con compañeros; la comunidad frontend es muy activa.
- **Participa en la carpeta `projects/`** para construir un portafolio real.

## 🤝 Contribución

Este proyecto es educativo y abierto a mejoras. Si encuentras errores, quieres añadir más ejemplos o mejorar las explicaciones, ¡las contribuciones son bienvenidas!

1. Haz un fork del repositorio.
2. Crea una rama con tu mejora (`git checkout -b mejora-modulo`).
3. Haz commit de tus cambios (`git commit -m "Añadida explicación sobre X"`).
4. Haz push a la rama (`git push origin mejora-modulo`).
5. Abre un Pull Request describiendo tu contribución.
